# Shared Deutsche Bank guide structure

All thirteen new firm pages now use the DB section structure rather than the abbreviated initial overview. The existing DB page remains intact.

Included: practitioner hero/bios, programme types and dated tracker rows, saved alerts/calendar downloads, firm research, student FAQs, paid private practitioner question, detailed role accordions/worked examples, briefing launch-list form, official news headlines, numerical example/practice, interview categories, Full Cycle profile preparation, 1:1 support and official sources.

Firm-specific data comes from the authored guide catalogue and tracker. Profiles and CV evidence come from the existing owned paid record. Existing scores are labelled as overall assessment scores, never new employer-specific scores. Drafts pass the current report validation before the endpoint returns them. Sample mode only reads the explicitly public fictional report.

News uses only configured official HTTPS newsrooms and links from the same host. No external newsroom scripts are executed. Unknown publication dates stay unknown; future-dated items are excluded. Some newsrooms use dynamic feeds or block retrieval; these show the official source link rather than invented headlines. Source checks on 16 October retrieved headlines for nine firms; Barclays, Citi, PwC and Intact require fallback links at present.

Questions store the selected firm in the existing bank field. The original DB route defaults to db, public answers are firm-filtered, private replies remain owner-protected, and the existing one-question-per-Full-Cycle-root limit is shared across guides. No actual questions, subscription messages or human notifications were submitted in verification.

Profile preparation uses saved evidence and deterministic guidance; reading it does not make a fresh model call, alter the target firm or change scores. Programme and alert data is still a source snapshot, not a vacancy-monitoring service. Reading guides and clicking Add firm create no charges.

Validation: thirteen full-template browser pages, category filters, sample profile, programme alerts/calendar, private-question lock, mobile overflow and JS errors; news domain/protocol/date guards; question routing/shared quota; calendar date and escaping guards; paid/anonymous endpoint checks on the preview.
