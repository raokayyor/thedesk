# WSO reference bank

Reviewed 13 November 2026. The source register, URLs, route tags, original practice prompts and short editorial summaries are in `lib/career-reference.mjs`.

The bank covers the public WSO investment banking, private equity, hedge fund, asset management, accounting, venture capital, behavioural and consulting guides. It also records layout observations from the user-supplied `wso_undergrad_resume_templatev7-11pt_font.docx`. It contains no full articles, copied answer banks, template candidate achievements or paid course content. Each web source contributes fewer than 200 words of summary and practice material.

`knowledgeBlock` supplies route-relevant research to the paid report (including CV repairs), application answer generation, interview drafts and interview feedback. Research is a separate editorial section, not labelled practitioner-approved. Staff-approved database entries keep their existing approval workflow. The bundled research remains available when that database is unavailable.

Use the material to identify useful missing evidence and explain concepts, never to fabricate student facts. The existing CV evidence validation still applies. This is prompt-time reference retrieval, not model fine-tuning. It does not alter the assessment rubric, saved scores, existing generated reports, permissions, or the CV export renderer. Generate a new report/draft to use the updated references.

Editorial qualifications: do not copy dated debt-ratio assumptions, blanket valuation rankings, fixed interview durations, firm-attributed questions or US resume conventions as universal rules. Employer process claims require separate verification. UK applicants keep their actual degree classification. Template examples are reference data only.
